# StockSense - Modular Inventory Management System

Please see the root [README.md](../README.md) for full project documentation, architecture diagrams, installation instructions, test execution, and API references.

## Key Folders:
- `frontend/`: React 19, Vite, Tailwind CSS, Lucide React, and React Router single-page application.
- `backend/`: Node.js Express REST API, Mongoose models, JWT auth, and StockService business logic.
- `database/`: Database schemas, seed scripts, backup/restore utilities, and architecture docs.
